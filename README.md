# Pokedanex

Web de col·leccionisme de cartes Pokémon: indica quines cartes i àlbums tens,
i descobreix el valor aproximat de la teva col·lecció i quant costaria
completar-la.

Aquest projecte és la part pràctica del **treball de recerca de 1r de
batxillerat** de l'Edanna Reves sobre el *vibe coding*: demostrar que es pot
crear una pàgina web útil **sense escriure ni una línia de codi** i amb un
pressupost màxim de **20 € al mes**.

## Contingut del repositori

| Carpeta | Contingut |
|---|---|
| `app/` | El codi de la pàgina web (generat íntegrament amb IA) |
| `docs/` | Planificació, especificacions, decisions i diari de desenvolupament |
| `treball/` | El treball de recerca escrit |
| `presentacio/` | La presentació final |
